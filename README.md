# NIGHTMARES

Двумерный игровой проект на Unity и C#. Проект включает исследование локаций, зоны скрытности, взаимодействие с предметами, инвентарь, головоломки, контрольные точки и бой с боссом.

## Запуск

1. Добавьте корень репозитория в Unity Hub через Add project from disk.
2. Откройте с Unity 2022.2.21f1 и дождитесь импорта пакетов.
3. Откройте `Assets/Scenes/menu.unity` и нажмите Play.

В репозитории находятся исходники Unity в `Assets`, `Packages` и `ProjectSettings`. Отдельные сборки и музыкальные треки в эту копию не входят.
